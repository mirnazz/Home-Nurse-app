# Nurse Home App

A Flutter mobile application that connects patients with qualified home nurses and simplifies booking home healthcare services.

---

## Current Status

Patient flow UI and navigation are completed.  
Backend integration will be added in later phases.

---

## Current Features

- Splash Screen
- Onboarding
- Role Selection (Patient / Nurse)
- Patient Authentication
  - Login
  - Create Account
  - Forgot Password
- Patient Home Dashboard
  - Search nurses and services
  - Quick services
  - Upcoming appointments
  - Recommendations
